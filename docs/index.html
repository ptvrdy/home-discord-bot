home-discord-bot

This is a personal automation project built and used solely by its developer, Peyton Tvrdy, for personal household and journaling use — a private Discord bot for home/task management and a set of tools that connect an Obsidian journal vault to a personal Google Calendar.

It is not a public product, service, or company. It has one user.
