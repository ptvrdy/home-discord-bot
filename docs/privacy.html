Privacy Policy

Last updated: September 2026

home-discord-bot is a personal automation project built and used solely by its developer, Peyton Tvrdy, for personal household task management and journaling. It is not a commercial product or service, and it has exactly one user: its developer.

What this accesses

With the developer's own explicit Google account authorization, this project reads Google Calendar event data (via the Google Calendar API) in order to display the developer's own schedule inside their own private notes and automated daily summaries.

How that data is used

Calendar data is read-only. It is used exclusively to display the developer's own schedule back to them. It is never sold, shared with, or made accessible to any third party, and is not used for advertising, profiling, or any purpose beyond that display.

Where it's stored

Any cached calendar data is stored on infrastructure the developer personally owns and controls (a private home server and personal devices), not on any third-party or commercial hosting platform.

Contact

Questions can be directed to the developer via github.com/ptvrdy.
